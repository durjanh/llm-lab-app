# Ledger

A small library that reads bank-export CSV files and reports spending by category and by month.

- Python 3, standard library only. Money is `decimal.Decimal`, never `float`.
- Run the tests from the project root with `python -m unittest`.
- Fix the code, not the tests. If you think a test is wrong, say so instead of changing it.
- Keep functions small, each with a one-line docstring.
