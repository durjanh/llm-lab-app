LLM Lab for AI engineers

See how large language models work, then build with them better

Twelve hands-on labs. Each one runs real models or real arithmetic in your browser, explains one mechanism, and ends with the engineering decisions it should change in your code.

Run it through the local server for the best experience: python python/server.py, then open http://localhost:8000. Opening the files directly also works, but the live Claude features and the full GPT-2 explainer need the server. See python/README.md.

Decision cheat sheet

Common problems, the first thing to try, and where to see why it works.

Get the same kind of answer every time, for extraction or classificationStructured outputs with a schema or enum, plus a few examples. On models that allow it, a low temperature.Prompting, Sampling
Answer from your own documentsRetrieval first, not fine-tuning. Chunk by structure, combine keyword and meaning search, set a threshold, and require citations.Embeddings & RAG, Training
Fix output in the wrong formatShow two or three input and output examples, then move to structured outputs if code reads the result.Prompting
Cut costMeasure tokens, shorten outputs, cache the stable prefix, trim history and tool results, and use a smaller model or lower effort for easy steps.Tokens, Context & cost, Live Claude
Choose between a large and a small modelMeasure both on your eval, try the large model at lower effort, and compare cost per correct answer, not per request.Routing, Live Claude

Reduce made-up factsGround answers in retrieved sources, allow "I don't know", and route low-confidence answers to a person.Embeddings & RAG, Confidence
Do exact maths, counting or string workGive the model a tool that runs code.Tokens, Agents & tools
Let the model take actionsStart with a fixed workflow. Use an agent loop only for open-ended tasks, with bounded iterations and approval for side effects.Agents & tools

Know whether a prompt change helpedBuild a labelled test set, run every version against it several times, and compare confidence intervals, not single scores.Evals

The browser models are GPT-2 (124M parameters, 2019), MiniLM and a small reranker, all tiny and old by today's standards. They are here because they show the mechanisms honestly and run on a laptop. Modern models are far more capable, but they work on the same principles.
